# Contributing

Thank you for improving Free Weights.

1. Open an issue describing the problem or proposed feature.
2. Create a focused branch from `main`.
3. Add or update tests for workout calculations and persistence behavior.
4. Run the Android and iOS checks documented in the root README.
5. Open a pull request with screenshots for visible interface changes.

Keep workout data local by default. Any future network feature must be opt-in and documented clearly.
